# Silver-ZSH
> Personal scripts, configs and extras for ZSH

### Quick install
> Backup old config (optional):
```bash
cd
mv .zshrc .zshrc-old
mv .p10k.zsh .p10k.zsh-old
```

> Install Silver ZSH:
```bash
cd
wget https://raw.githubusercontent.com/serainox420/Silver-ZSH/refs/heads/personal/config/.zshrc
wget https://raw.githubusercontent.com/serainox420/Silver-ZSH/refs/heads/personal/config/.p10k.zsh
source .zshrc
```
